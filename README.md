# CEA-Intismeran
Cost-effectiveness analysis of Intismeran (mRNA-4157) + Keytruda vs Keytruda alone for adjuvant melanoma.

## Structure
- `model.py` — PSM core + parameter inputs + base case
- `data/` — cost/utility inputs (to be filled from literature)
- `analysis.ipynb` — results + figures

## Target
PharmacoEconomics → Gene/Cell Therapies collection
